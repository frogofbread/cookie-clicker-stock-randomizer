# cookie-clicker-stock-randomizer
A script made to emulate the cookie clicker stock randomizer.  
In order to use main.lua, please change all variables. TTMC is time until mode change.  
In order to use alternateversion.lua, input in order of price, mode, time till mode change, and delta.  
Warning; the alternate version may be outdated, use main.lua as I rewrote it recently in order to align with any potential changes since the first release.
